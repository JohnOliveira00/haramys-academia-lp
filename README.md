# 🏋️‍♂️ Haramys Academia - Landing Page

![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white)

Uma landing page moderna, responsiva e de alta conversão desenvolvida para a **Haramys Academia**. O objetivo principal da página é atrair novos alunos, destacando a estrutura nova com equipamentos de última geração, modalidades inclusas (Musculação, Jiu-Jitsu, Muay Thai e Fit Dance) e a facilidade do uso de benefícios corporativos como Gympass e Totalpass.

--- 
 
## Funcionalidades

- **Design Premium:** Paleta de cores moderna (Preto, Vermelho e Branco) alinhada à identidade visual da marca.
- **Foco em Conversão (CTA):** Botões estratégicos para agendamento de **Aula Experimental Grátis**.
- **Seção de Modalidades:** Apresentação das aulas de lutas e dança inclusas no pacote.
- **Prova Social:** Espaço dedicado para depoimentos reais de alunos.
- **Seção FAQ:** Dúvidas frequentes integradas de forma limpa para quebrar objeções dos visitantes.
- **100% Responsivo:** Otimizado para uma experiência fluida em smartphones, tablets e computadores.

---

##  Tecnologias Utilizadas

O projeto foi construído utilizando o ecossistema web clássico, garantindo leveza, carregamento rápido e excelente SEO:

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização customizada, Layout em Flexbox/Grid e responsividade.
- **Font Awesome:** Ícones modernos e visuais (via CDN).
